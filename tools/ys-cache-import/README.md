# YS CACHE Auto Import

[繁體中文](#ys-cache-自動匯入)

Install YS CACHE and activate this companion plugin. It looks for compatible settings, switches the active cache plugin, and imports the supported settings automatically. Open **Tools → YS CACHE Auto Import** to see the result or retry on a standalone WordPress site.

- Imports the cache lifetime from one second to seven days, path, cookie, and user-agent exclusions, and compatible Cloudflare settings.
- Imports an image CDN hostname when the source configuration supports it.
- If the switch is interrupted, the importer schedules a rollback and reports its status on the same screen.
- Updates to an already active importer keep the installed settings. Reactivate it when you want to trigger a new automatic import.

# YS CACHE 自動匯入

[English](#ys-cache-auto-import)

先安裝 YS CACHE，再啟用此匯入工具。工具會自動找出相容設定、切換快取外掛並匯入支援的設定。請到 **工具 → YS CACHE 自動匯入** 查看結果，或在獨立的 WordPress 網站上重試。

- 匯入快取效期（1 秒至 7 天）、路徑、Cookie、User-Agent 排除規則及相容的 Cloudflare 設定。
- 來源設定相容時會匯入圖片 CDN 主機名稱。
- 切換若中斷，工具會排程恢復原外掛狀態，並在同一頁顯示結果。
- 更新已啟用的匯入工具會保留現有設定。需要再次觸發自動匯入時，請重新啟用匯入工具。
